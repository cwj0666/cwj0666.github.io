서비스 기획, 데이터 설계, AI 모델 평가와 구현 경험을 정리한 정적 포트폴리오입니다.

- **Cofathon**: 웰니스 기획전 자동화, AI 에이전트 병렬 개발과 독립 검토

## 구성

`index.html`은 소개와 프로젝트 요약입니다. 상세 사례는 `seorap.html`, `cms.html`, `cofathon.html`에서 제공합니다. `original-extension.css`, `design-system.css`, `project-pages.css`, `assets/`, `icons/`를 공유합니다. 주요 내용과 아티팩트는 펼치기 동작 없이 확인할 수 있습니다.

## 로컬 실행

```sh
python -m http.server 8766
```

GitHub Pages의 `main` 브랜치 루트에서 게시합니다. `.nojekyll`을 포함해 별도 빌드 없이 정적 파일을 제공합니다.

## 자료와 출처

서비스 화면, CMS 설계도와 Grafana 화면은 프로젝트 자료입니다. 모델 성능 그래프는 저장된 평가 결과를 기반으로 작성했습니다. 고객 상황 이미지와 일부 설명 도식은 생성형 이미지 도구로 제작했습니다.

기술 로고는 [Simple Icons](https://simpleicons.org/), 기능 아이콘은 [Lucide](https://lucide.dev/)를 사용합니다. 관련 라이선스는 `icons/`에 포함되어 있습니다. 본문 글꼴은 [Pretendard](https://github.com/orioncactus/pretendard), 코드 글꼴은 [JetBrains Mono](https://www.jetbrains.com/lp/mono/)입니다.
